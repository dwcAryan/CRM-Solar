# Solar CRM User Manual (PDF)

The official **Solar CRM User & Operations Manual v1.0** is available directly inside the application for offline reading, training, and operational reference.

## Accessing the User Manual
1. **From the User Menu**: Click on your profile avatar in the top-right header, and select **"User Manual (PDF)"**.
2. **From the Help Assistant**: You can ask the Help Assistant "Where is the user manual?" or "How do I download the PDF manual?".
3. **Direct PDF Link**: Authenticated users can open `/api/docs/manual/` in their browser to view or download the PDF document.

## Language Editions
- **English**: `Solar_CRM_User_Manual_v1.0.pdf`
- **हिन्दी (Hindi)**: `Solar_CRM_User_Manual_v1.0_hi.pdf` (automatically served when your interface language is set to Hindi)

## Contents Covered in the Manual
- Full sales pipeline walkthrough from New Lead to Won (Call, Survey, Quote, Won)
- Detailed guides for each role (Salesperson, Manager, Surveyor, Admin)
- Operating across India and Australia (compliance, time zones, currencies, calling hours)
- Full tables of Call, Survey, and Quote outcomes with retry ladders
- Step-by-step procedures for CSV imports, audits, quotes, and surveys
- Security best practices, FAQs, keyboard shortcuts, and troubleshooting tables
